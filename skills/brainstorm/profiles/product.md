# Product profile

A need that has users: a feature, a tool, a service.

## Branches of the tree

In the order they unlock:

1. **For whom**: who uses it, how many, at what level, in what context.
2. **Problem**: what is stuck today, how it is worked around, what the status quo costs.
3. **Expected outcome**: how success shows (a shorter gesture, a number, a complaint that disappears).
4. **Scope**: the smallest set that delivers the outcome (MVP), and what is explicitly out of scope.
5. **Journey**: the steps of the main use, the edge cases (empty, error, volume).
6. **Constraints**: budget, deadline, platform, data, privacy.
7. **Next**: who builds, when it is measured.

## Default deliverables

`spec` recommended; `prd` if several people must arbitrate; `plan` or `issue` if the work starts right away.
