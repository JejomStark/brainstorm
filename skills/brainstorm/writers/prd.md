# Writer: PRD

File: `deliverables/prd.md`. The PRD aligns several people on the problem before the solution.

```md
# PRD: <name>

## Problem
<who suffers from what, with evidence (attachments, figures)>

## Target users
<segments, with their context of use>

## Goals and metrics
| Goal | Metric | Target |
|---|---|---|

## Requirements
<by priority: must have, should have, nice to have>

## Out of scope

## Risks and dependencies

## Milestones
```

Write it in the session language, headings included.
