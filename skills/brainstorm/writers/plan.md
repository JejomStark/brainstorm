# Writer: task plan

File: `deliverables/plan.md`. A plan splits the work into ordered tasks, each deliverable and verifiable on its own.

```md
# Plan: <name>

## Goal
<one sentence>

## Tasks
1. **<task>**: <what is done>. Done when: <criterion>. Depends on: <no. or nothing>.
2. …

## Risks and checkpoints
```

Order by dependency then by value: the first task already delivers something usable or demonstrable. Write it in the session language, headings included.
