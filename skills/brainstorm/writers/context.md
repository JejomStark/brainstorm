# Writer: glossary (CONTEXT.md)

Format from *domain-modeling* (Matt Pocock, MIT). File: `deliverables/CONTEXT.md`; offer to merge it into the repository's `CONTEXT.md` if one exists.

```md
# <Name of the context>

<One or two sentences: what this context is and why it exists.>

## Language

**<Term>**:
<One or two sentences: what it is, not what it does.>
_Avoid_: <rejected synonyms>
```

Only the terms specific to the domain, never general programming notions. One term per concept: the other words go under "Avoid". Write it in the session language, headings and labels included.
