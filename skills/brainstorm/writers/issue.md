# Writer: issue

File: `deliverables/issue.md`. An issue can be picked up without a meeting: it carries its context and says when it is done.

```md
# <Title in the imperative>

## Context
<why now, 2 to 4 lines>

## To do
<the expected change, one bullet per item>

## Acceptance criteria
- [ ] …

## Out of scope

## References
<attachments, links, related deliverables>
```

Publish nothing: the user decides where the issue goes. Write it in the session language, headings included.
